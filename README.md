# Site de Kelly Goffaux – Psychologue à Morlanwelz

Site vitrine statique (une page), publié avec GitHub Pages.

- `index.html` : la page complète (textes, styles, animations)
- `images/` : photos du cabinet et portraits
- `sitemap.xml` et `robots.txt` : pour Google et Bing

Pour modifier un texte : éditer `index.html` directement sur GitHub (icône crayon), puis « Commit changes ».
Le site se met à jour tout seul en 1 à 2 minutes.
